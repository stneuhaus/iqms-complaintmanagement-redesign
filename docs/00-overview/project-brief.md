# Project brief

**Project:** iqms-complaintmanagement-redesign

## Purpose

Document the current product technical complaint (PTC) / PV-related complaint handling process and collect requirements for the IQMS complaint-management redesign, so the process can later be automated with n8n.

## Current phase

Requirements collection and as-is process documentation.

## Intended later deliverables

- Architecture diagram
- Functional specification
- Design specification
- n8n workflows

## Scope (draft)

In scope:

- Understanding intake, triage, case creation, translation, AE handling, reimbursement, and sample logistics as they work today
- Identifying systems, roles, and handoffs that an automation would touch

Out of scope for this phase:

- Implementing n8n workflows
- Changing SOPs or production systems
