# Glossary

| Term | Meaning |
| --- | --- |
| AE | Adverse event |
| Argus | Safety / AE reporting system; today notified manually from the complaint process |
| GBS | Global Business Services (country–product lists on SharePoint in as-is notes) |
| IQMS | Quality / complaint case system used to register PTCs |
| Miidas | Interface that can create IQMS cases and attachments |
| n8n | Workflow automation platform planned for this project |
| PTC | Product technical complaint |
| PV | Pharmacovigilance |
| SSF | Service request / ticket tool used for triage, follow-up, and subprocesses |
| Synaps | Consumer Health application / site and organisation master data |
| Translation hub | Machine translation with human check; original and translation stored as attachment |
